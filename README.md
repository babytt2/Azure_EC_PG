# Elastic Clusters MVU Validation Guide

by Yujin Cho

[고객용 웹 가이드](https://babytt2.github.io/Azure_EC_PG/)

Architecture, 검증 환경, 측정 결과와 운영 준비 절차를 카테고리별로 정리한 정적 웹 가이드입니다.

메인 파일은 `index.html`이며 개념도와 차트, 스타일과 검색 기능을 파일 안에 포함합니다.

측정 기준일은 2026-10-25입니다. 결과는 해당 시험 조건에 한정되며 제품 SLA 또는 공식 지원 범위를 대신하지 않습니다.

현재 지원 범위와 실행 방법은 [공식 제품 문서](https://learn.microsoft.com/azure/postgresql/elastic-clusters/)를 확인하세요.
